# Dados

`frequencia_en.txt`: as 20.000 palavras mais frequentes do inglês falado, em ordem (a linha é a
posição), tiradas das legendas do OpenSubtitles 2018. Serve para medir o vocabulário de um título
(S48, `nivel_de_ingles.go`).

Fonte: [FrequencyWords](https://github.com/hermitdave/FrequencyWords), de Hermit Dave
(`content/2018/en/en_50k.txt`, só a coluna das palavras, as 20.000 primeiras). Conteúdo sob a
licença [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); este arquivo, adaptado
dele, fica sob a mesma licença.
